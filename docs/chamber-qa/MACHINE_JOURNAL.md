Its ray-only observation path writes no beam map or audio events. Pressure reports cargo only when a real cargo collider overlaps the sensor.

Missing readings, sample gaps, incomplete intervals and truncation make negative conclusions UNKNOWN. A shutter that moved partly but never fully opened did not remain closed. Full opening and later current closure remain separate facts. Light-return wording requires a witnessed loss first.
