An original compact cargo module was authored locally in Blender5.2 using actual beveled hard-surface meshes: ceramic hull, graphite impact ribs, recessed carry handles, aluminum fasteners/hatch and restrained amber latches. This is original game art, not a Tripo output or a claim that search produced an exact owned crate. The module is deliberately fitted to a simple box proxy and the bright ceramic/graphite facility. Full source, editable blend, exported GLB, proof render and metrics are retained. No external texture or brand was used. See `ASSETS.md`.

Porter reuse as a scripted guide is optional; only a real AnimationMixer clip counts as skeletal animation. No desk or banker lamp belongs in the new world.
