## Producer rules

- Start every new attempt with no completed-event claim, even if its first sensor reading is already OPEN/AT/PRESSED. A genuine observed full-pose/contact transition supplies a positive event. Opening/arrival commands and start cues do not.
- Pair the report with current native pose/contact/light. A previous arrival remains a past fact after departure; say **not at that dock now**, not **has not arrived**, unless complete observation genuinely establishes no arrival. Prefer avoiding that unnecessary negative entirely.
- A generic MOVING state does not establish rising/descending. Report “is moving.” Full native direction would be needed for a directional verb.
- Picking up a cube is not automatically vacating a plate: a held body can still touch it. EMPTY must come from the fresh native receiving contact, not E/pickup history.
- Use an observed timestamp only when that actual event time is retained. A report whose positive evidence is unavailable is withheld/UNKNOWN. Negative interval claims require complete coverage and obey truncation/reset rules. Bounded positive fact retention, if added, stays per watched ID/attempt and never invents initial history.
- Reports can describe the remaining action for the current base/contrast instruction; that changes text only. Both fixtures remain identical and physically equivalent solutions are accepted. No report-read, report-accepted, milestone-count or grammar-answer gate is introduced.
