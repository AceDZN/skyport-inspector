# Chamber reset targets

Generated with the built-in imagegen tool before the enclosed chamber rebuild. Both targets were opened and inspected at full size. They are design targets, never gameplay evidence.

The first establishes a continuous enclosed test facility, white ceramic inset portal surfaces, dark structural ribs, actual ceiling lighting, transparent partition, one weighted cube, pressure button and exit door connected by a visible conduit. The second establishes the necessary vertical separation and launch gap with an enclosed catch pit and elevated receiving gallery. The generated prop resembles the familiar franchise too closely; runtime art will use an original rectangular split-coil instrument instead.

Runtime comparison must inspect actual gameplay images for enclosure, light/material hierarchy, portal perspective, button/door readability, device visibility and first-person composition. No photorealistic parity claim follows from these mockups.
