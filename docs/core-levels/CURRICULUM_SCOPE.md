# Current numbered campaign: selected English practice

This document describes the current Rapier-based fifty-room campaign in `src/core/levels/`. The older nine-room `g7/g8/g9` mission table in the root curriculum file is retained history, not coverage for this campaign. Player progression is numbered 1–50; source grade labels identify teaching material internally and never restrict access by age or grade.

The game asks players to read a short instruction and apply its meaning to a real physical problem. Later rooms offer several plausible objects, supplies or destinations. An instruction identifies which relationship matters: for example, the receiver powering a platform, the object blocking a beam, or the location referred to by a reported instruction. M pauses the puzzle for optional Hebrew/vocabulary support. Configured N journals distinguish genuinely observed machine events from current state. Results recap the language focus; none of those reading controls awards progress.

All missions and physical puzzles are original game work. Workbook is the source of selected teaching rules and examples of usage; it did not author these rooms, models, tests or game assets. This is not a Workbook endorsement or a claim to reproduce a whole curriculum. Exact canonical source URLs and the intended practice are retained next to each authored entry. Raw-source hashes and acquisition scope are in [later-language provenance](../curriculum/later-language-source-provenance.json), [event provenance](events-26-30-source-provenance.json), [31–50 provenance](planning-31-50-source-provenance.json), and the earlier saved source packs.

The authored contrasts keep the same physical candidates and circuits while changing a meaningful request. A wrong branch can remain physically traversable; feedback identifies the route relationship instead of requiring a grammar answer to power machinery. Equivalent cargo allocations, optional rides and other physically sufficient solutions remain valid where the sentence allows them. No read-message, launch-count, original-cube identity or old-arrival flag substitutes for current physical support and supplies.

Authored source, finite native contracts, ordinary-input completion and learning are different evidence. The final campaign review status is recorded separately in [the v3 release status](../chamber-qa/fifty-final-v3/RELEASE_STATUS.md). Completing the route does not establish unaided comprehension or retained mastery. The game does not assess free grammar production, extended writing, the full tense/modal/passive/reported-speech systems, listening, speaking or pronunciation.
